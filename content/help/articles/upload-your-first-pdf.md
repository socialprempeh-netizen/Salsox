Every document starts as a PDF. The original file is never changed: signatures are added to a separate, sealed copy once everyone has signed.

## Upload a PDF

1. In the dashboard, select **Documents**, then **New document**.
2. Select **Tap to choose a PDF, or drop it here** and pick your file. On a computer you can also drag the file onto that box.
3. Optionally type a **Title**. If you leave it empty, the file name is used.
4. Select **Continue to recipients**. The document opens in the editor, on the **Recipients** step.

From here, follow [Send a document step by step](/resources/help/send-a-document-step-by-step).

## Good to know

- **PDF files only, up to 4 MB.** A Word file needs to be saved or exported as a PDF first. If your PDF is too big, see [My PDF won't upload](/resources/help/pdf-wont-upload).
- **In a hurry?** [Quick Send](/resources/help/quick-send) skips the editor: it places a signature and a date for each signer for you.
- Nothing is sent when you upload. The document waits under **Documents**, filter **Drafts**, until you send it.
