Anyone can check a document signed here, without an account. The check shows who signed and when, never what the document says.

## Verify a document

1. Find the **verification code** on the certificate page at the end of the signed PDF, under the QR code. Scanning the QR code with a phone opens the check with the code filled in.
2. Otherwise, go to the [verification page](/verify) and type the code. Older documents show only a document ID, which works too.
3. Optionally, under **Also check the file**, choose the signed PDF. It's checked on your device and never uploaded.
4. Select **Verify document**.

## Read the result

5. **Genuine signed document** means it's a completed record, signed by everyone it was sent to. You see each signer (with their email masked), their role and when they signed.
6. With a file chosen, **This file is the sealed copy** means it hasn't changed since sealing, byte for byte. **This file is not the sealed copy** means it was edited, re-saved or printed to PDF: ask the sender for the original download.
7. **No signed document matches** means the code is mistyped, or the document isn't completed yet. Only completed documents can be verified.
