- Have a **completed** document signed by **Kofi Boateng** (kofi.boateng@example.com), with its signed PDF downloaded to the desktop.
- Use IP addresses from the documentation range (203.0.113.x) in any test data shown on screen.
- An authenticator app on a phone, for scene 5.

## Script

### Scene 1: Introduction

**On screen:** the completed document's page.

**Say:** "Every document keeps a complete record of what happened to it. Here's what's recorded, and how anyone can check a signed document is genuine."

### Scene 2: The audit trail

**Do:** scroll to **Audit trail**.

**Say:** "This is the audit trail. Every action is here, newest first: uploaded, sent, opened, each field completed, signed, and completed by all parties. Each one has the time, the person's email and their IP address. Entries can't be edited."

### Scene 3: The sealed PDF

**Do:** under **Files**, select **Signed PDF + certificate**, and open it. Scroll to the last page.

**Say:** "When the last person signs, the document is sealed. Your original file is never changed: the signatures go onto a signed copy. On the Business plan, the last page is a certificate with the same audit trail, and a verification code."

### Scene 4: Verify a document

**Do:** open the **verification page**, type the code from the certificate, choose the signed PDF under **Also check the file**, and select **Verify document**.

**Say:** "Anyone can check it on our verification page, without an account. Type the code, or scan the QR code. You can also choose the file: it's checked on your own device, never uploaded. Genuine signed document, and this file is the sealed copy, byte for byte. If someone had edited it, it would say so."

### Scene 5: Two-factor authentication

**Do:** go to **Settings**, find **Two-factor authentication**, and select **Turn on**. Stop before the QR code is shown.

**Say:** "And protect your own account: in Settings, turn on two-factor authentication. Scan the code with an authenticator app, enter the six-digit code, and save your backup codes somewhere safe."
